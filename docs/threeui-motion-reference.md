# Three-dimensional motion reference

The original ThreeUI references informed the decision to use dimensional depth sparingly. The current production implementation is an original scroll-built construction sequence in `src/ui/screens/HomeScreen/ScrollConstructionHero.tsx`, `constructionScene.ts` and `constructionHouse.ts`.

The model assembles from foundation to completion, reverses with scroll, pauses when scrolling stops, and provides static fallbacks for reduced motion and unavailable WebGL. No ThreeUI source code or assets are included.
